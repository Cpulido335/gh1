## GH1 🎸

GH1 is a portable game system; it is a Guitar Hero style arcade rhythm game running on
an STM32F4 Micro Controller (GH1-a) and displayed on an ILI9341 Display. GH1 plays
audio by streaming a .wav file from an onboard microSD card. The microSD card is
inserted into GH1-a’s MicroSD Slot. Five columns feed colored notes down the screen in
sync with a song; the player has to hit the corresponding note with precise timing to
achieve the maximum score. The five colored arcade LED buttons have colors that
correspond to the color of notes on the game.
